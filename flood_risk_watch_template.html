How this model works

A CatBoost gradient-boosted classifier is trained on 500,000 synthetic weather, soil, terrain and land-use records across the three states, predicting the probability of flooding at a given point in time.

Rainfall (last 3h–7d), height above nearest drainage (HAND), modelled runoff and soil moisture are the strongest predictors — see the panel alongside the map for the full ranking.

Path to real-time monitoring

The supplied CatBoost model remains unchanged. refresh_live_data.py fetches live test features, re-scores the same trained model, and writes the resulting values back into this exact map/data format:

✓ Open-Meteo (weather & rainfall) ✓ Open-Meteo Flood API (GloFAS discharge) ✓ NASA POWER (rainfall climatology) △ IMD district rainfall/warnings △ Bhuvan/NRSC flood hazard IMD official API NASA GPM IMERG NASA SMAP (soil moisture) ERA5 / Copernicus CDS Sentinel-1 SAR HydroSHEDS / DEM OpenStreetMap JRC Global Surface Water △ NVIDIA FourCastNet

✓ = live and free right now. △ = free and keyless but built on endpoints IMD/NRSC haven't published as a stable public API, so they're off by default and can fail silently. The rest need a free registration before they'll return anything. See the comments at the top of refresh_live_data.py for exactly which flag turns each one on.

District boundaries are simplified 2011 Census administrative boundaries from a public open-data GeoJSON collection. Flood probabilities are model outputs on synthetic data — not an official warning system. For real flood alerts, always follow India Meteorological Department and state disaster management authority advisories.
